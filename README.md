# Air-pollution-risk-mapping-with-Sentinel-5P-and-socio-environmental-indicators---story-assets
This repository contains the files and assets used to create the story documenting Group 1’s activities during ESA Challenge Week in September 2026.

Repository contents
The repository includes 18 images and 14 vector files.

Vector files
The 14 vector files are provided in GeoJSON format, using the WGS 84 coordinate reference system (EPSG:4326).

The RISK_IDX attribute contains the risk index value used to visualize risk for each district.

Images
The 18 images include:

Administrative boundaries.

Total population per district.

Percentage of residents aged over 80 per district.

The relationship between ground-based and satellite measurements of NO₂.

Fourteen maps showing pollution values per district.
